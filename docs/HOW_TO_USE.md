# Earth Jukebox 使用说明

网址：https://bep23020002-collab.github.io/earth-jukebox/
建议戴耳机（左右声道有意义）。iPhone 请先关掉静音模式。

---

## 0. 打开网站
有三个按钮：
- **Start listening**：一般使用，不会自动念出文字（第一次会出现五步新手引导，见最下面）
- **中文语音导览**：中文的语音导览
- **Start with voice guide**：每一步都会念出来，给看不见屏幕的人用。语音导览有英文和中文：电脑按 Start with voice guide 或 中文语音导览；手机在第一个画面上半部快速点两下是英文、下半部是中文，之后随时按 中文 / English 切换。手机上整个屏幕会变成遥控器：上半部中间是 Where am I?，上北、下南、左西、右东；最下面是 Play、Next place、Help、More；More 打开第二个画面（Back、声音代表什么、加进旋律、前一年、后一年、Slower、Faster、中文/English、Close）。按钮点一下念出它是做什么的，再点一下才按下去；每按一次会建议一件还没试过的事。遥控器以外的地方像读屏软件：点一下念出来，再点一下才按下去；按住不动再滑，手指经过的都会念

顶部有 3 个分页：**Play**、**My Earth song**、**Ask the Earth**

顶部一直看得到两个键（给看不见屏幕的人，也让评审一眼看到）：
- **Voice guide**：语音导览开关，开着时小灯变橘色，每一步都会念出来（键盘按 `V` 也可以）。开着时，鼠标停在任何按钮、文字、读数卡、乐谱框（会说有几个音、最新的是高还是低、整体往上还是往下）、颜色条上，都会念出来；鼠标在地球上移动、或一根手指在手机上滑，会一路弹出音，停一下就念出地点；快速点一下才会加进旋律，两根手指是转地球。用 VoiceOver / TalkBack 的人要关掉，因为读屏软件已经会念，否则会念两次。
- **Controls**：打开一个按键面板，放在年份条下面：North / South / East / West 移动，中间橘色的 **Where am I?** 说出现在的位置和温度，还有 **Year before / Year after**、**What do the sounds mean?** 和 **Add this place to my tune**（把这里加进旋律，加满 3 个就能走完导览）。手机没有方向键，靠这个面板一样能用；电脑上每个按钮旁边会显示对应的键。

## 1. Play（玩地球）
### 新手引导
第一次按 Start listening（或用电脑开语音导览）会出现五步新手引导：页面变暗，只亮出一个地方，旁边有说明框。
1. 点地球（点了自动下一步；用方向键、Enter 或大按钮也算）
2. 按 Play 听 1880 到 2025（播完自动下一步）
3. 其他 NASA 地图和太空站
4. 为看不见地图的人而做：Voice guide 和 Controls（打开语音导览也会自动下一步；已经开着语音导览就没有这一步）
5. 我的地球之歌、问地球
每一步都可以按 Skip 或 Esc 跳过，键盘按 N 是下一步。没开语音导览时，每个浏览器只会自动出现一次；**开着语音导览时每次都会从头讲一遍**（看不见的人没有画面可以提醒）。上次用过语音导览的人再打开网页，点一下任何地方或按任何键就会直接进入。手机上用两根手指点一下任何地方，可以叫出遥控器或重听说明。要再看，打开 More ways to listen，按 Show me around again，或者用无痕视窗打开。手机开语音导览时不会出现（那时整个屏幕是遥控器）。
